## 참고 — 앱테크 코인 로티 재생 타이밍

리캡 아이콘 오른쪽의 앱테크 코인 로티는 **기존 파일 그대로**이고, 두 로티가 동시에 움직이지 않도록 **재생 시작 딜레이만** 아래 기준으로 맞춥니다.

- 코인은 화면 진입 후 딜레이 동안 **첫 프레임에서 정지** → 딜레이가 끝나면 재생 시작 → 계속 반복합니다.
- 딜레이는 코인 왼쪽 아이콘 자리의 상태에 따라 달라집니다.

| 코인 왼쪽 아이콘 자리 | 코인 재생 딜레이 |
|---|---|
| 로티일 때 (**리캡 아이콘** — 이번 건) | **2.8초** |
| 뱃지 모션이 있을 때 (체크인 아이콘 + "이벤트" 배지) | 4.5초 |
| 정지 이미지일 때 | 0초 |
| 아이콘이 없을 때 | 0초 |

- 리캡 로티 파일을 못 불러와 정지 이미지로 보일 때도 '정지 이미지' 기준(0초)입니다.
- 지면을 전환하면 리캡 로티와 코인 모두 처음부터 다시 시작합니다 (리캡 즉시 재생, 코인은 딜레이부터).
- 코인 로티 파일(지면별 색 white · black · kids)은 기존과 같습니다. 이번 전달 범위가 아닙니다.
