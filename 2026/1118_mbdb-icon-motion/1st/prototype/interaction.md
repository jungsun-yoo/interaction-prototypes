# [무배당발] 랭킹판·세일판 무배당발 아이콘 모션 — 인터랙션 정의

세일판 **무배당발 탭**과 랭킹판 **무배당발 띠배너**의 무배당발 아이콘(트럭)에 모션을 넣습니다. 필터(퀵필터)에 적용된 무배당발 아이콘 모션과 같은 움직임이고, 한 바퀴 뒤에 정지 구간을 두고 반복합니다.

## 1. 구현 방식

| 플랫폼 | 방식 | 전달물 |
|---|---|---|
| 앱 (iOS · Android) | **Lottie** | `download/mbdb_icon_lottie.zip` (3종) |

- 두 방식의 움직임(시간 · 곡선 · 이동 거리)은 같습니다. 아래 3장의 타임라인이 공통 기준입니다.

## 2. 적용 위치와 색상

| 위치 | 상태 | 배경 | 아이콘 색 (심볼 / 로고타입) | 로티 파일 | 크기 |
|---|---|---|---|---|---|
| 세일판 무배당발 탭 (TabOutlinedItem) | 선택 | 흰색 · 테두리 검정 | `#245EFF` / `#021E65` | `mbdb_icon.json` | h18 |
| 〃 | 미선택 | 투명 · 테두리 `#CCCCCC` | `#8A8A8A` / `#8A8A8A` | `mbdb_icon_gray500.json` | h18 |
| 랭킹판 무배당발 띠배너 | 미체크 | `#EBEBEB` | `#245EFF` / `#021E65` | `mbdb_icon.json` | h16 |
| 〃 | 체크 | `#00216D` | `#FFFFFF` / `#FFFFFF` | `mbdb_icon_white.json` | h16 |

- 아이콘 = 심볼(트럭) + 로고타입(무배당발 글자). **움직이는 것은 심볼(트럭)뿐**이고 로고타입은 고정입니다.
- 탭 버튼: 81 × 32, 패딩 위아래 7 · 좌우 6, 둥글기 4, 테두리 1 (안쪽).

## 3. 모션 타임라인 (공통)

트럭 두 대(A · B)가 심볼 칸 안에서 좌우로 이동합니다. 칸 밖으로 나간 부분은 잘려서 보이지 않습니다.

- 한 바퀴: **5.2초** = 모션 2.5초 + 정지 2.7초, 계속 반복
- 이동 거리: 심볼 칸 폭만큼 (h18 기준 20, h16 기준 18)

### 트럭 A (처음부터 보이는 트럭)

| 구간 | 시간 | 움직임 | 곡선 |
|---|---|---|---|
| 정지 | 0 ~ 0.167초 | 제자리 (x 0) | — |
| 나감 | 0.167 ~ 0.667초 | x `0 → +칸 폭` (오른쪽으로 빠짐) | `cubic-bezier(0.6, 0, 0.4, 1)` |
| 대기 | 0.667 ~ 1.533초 | 칸 밖에서 대기 (숨김) | — |
| 들어옴 | 1.533 ~ 2.033초 | x `-칸 폭 → 0` (왼쪽에서 들어옴) | `cubic-bezier(0.167, 0.167, 0.2, 1)` |
| 정지 | 2.033 ~ 5.2초 | 제자리 (x 0) | — |

### 트럭 B (중간에 한 번 지나가는 트럭)

| 구간 | 시간 | 움직임 | 곡선 |
|---|---|---|---|
| 대기 | 0 ~ 0.45초 | 칸 밖 왼쪽 (숨김) | — |
| 들어옴 | 0.45 ~ 0.95초 | x `-칸 폭 → 0` | `cubic-bezier(0.167, 0.167, 0.2, 1)` |
| 정지 | 0.95 ~ 1.25초 | 제자리 (x 0) | — |
| 나감 | 1.25 ~ 1.75초 | x `0 → +칸 폭` | `cubic-bezier(0.6, 0, 0.4, 1)` |
| 대기 | 1.75 ~ 5.2초 | 칸 밖 (숨김) | — |

- 화면에서는: A가 오른쪽으로 나가는 사이 B가 왼쪽에서 들어와 잠깐 멈췄다 나가고, B가 나가는 사이 A가 다시 들어와 제자리에서 정지합니다.
- 트럭이 멈춰 있는 시간은 한 바퀴 끝 정지(2.033 ~ 5.2초)와 다음 바퀴 시작 정지(0.167초)를 합쳐 약 3.33초입니다.

## 4. 앱 — Lottie

| 항목 | 값 |
|---|---|
| 파일 | `mbdb_icon.json` · `mbdb_icon_white.json` · `mbdb_icon_gray500.json` (`download/mbdb_icon_lottie.zip`) |
| 규격 | 69 × 18 (심볼 20 × 18 + 로고타입 49 × 18 한 덩어리), 60fps, 312프레임(5.2초) |
| 배경 | 투명 |
| 재생 | 반복 재생 (정지 2.7초가 파일 안에 포함) |
| 그래픽 | 피그마 벡터를 쉐잎으로 옮김 (이미지 없음) |

- h16 자리(랭킹판 띠배너)에는 같은 파일을 비율 그대로 줄여 씁니다(61.33 × 16).
- 트럭은 20 × 18 프리컴프 안에서 움직이므로 칸 밖으로 나간 부분은 잘리고 로고타입과 겹치지 않습니다.

## 5. 웹 — CSS animation

| 항목 | 값 |
|---|---|
| 파일 | `src/mbdb-icon-motion.css` |
| 구조 | 심볼 칸(`overflow: hidden`) 안에 같은 트럭 이미지 2장(`img:nth-child(1)` = A, `(2)` = B)을 겹쳐 둠 |
| 재생 | 칸에 `is-play` 클래스 → 반복 재생 / `is-once` 를 같이 붙이면 한 바퀴만 |
| 길이 | `animation-duration: 5200ms`, 키프레임 % = 3장 시간 ÷ 5.2초 (소수점 둘째 자리) |
| 이동 거리 | `translateX(calc(±100% ± 2px))` |
| 곡선 | 3장과 같음. 단 `0.167` 은 퀵필터 CSS 원본대로 `0.17` 로 반올림해 씀 (눈으로 차이 없음) |

```html
<span class="mbdb-icon-motion is-play" aria-hidden="true">
  <img src="mbdb_symbol_on.png" alt="">
  <img src="mbdb_symbol_on.png" alt="">
</span>
```

- 이동 거리에 2px 를 더한 이유: 트럭 그림이 이미지 왼쪽 끝에 붙어 있어서, 칸 폭(100%)만큼만 밀면 소수점 위치에서 가장자리 픽셀이 번져 트럭 뒷부분이 1px 정도 남아 보입니다. **웹 전용 보정**이고 앱(Lottie)에는 없습니다.
- 트럭 이미지(3배 PNG): 탭 `mbdb_symbol_on.png` · `mbdb_symbol_off.png` (20 × 18), 띠배너 `mbdb_symbol_h16.png` · `mbdb_symbol_white_h16.png` (18 × 16)

## 6. 재생 정책

| 항목 | 정책 |
|---|---|
| 재생 조건 | 아이콘이 **화면에 보일 때만** 재생. 화면 밖으로 나가면 멈춤 |
| 상태가 바뀔 때 | 탭 선택 · 띠배너 체크를 바꾸면 바뀐 색의 모션을 **처음(0초)부터 다시 재생** |
| 움직임 줄이기 | 기기 설정의 움직임 줄이기와 **상관없이 재생** |
| h16 크기 | 로티를 h16 으로 줄여 씀 (61.33 × 16). 기존 띠배너 로고 62 × 16 보다 0.67 좁지만 **그대로 둠** |
| 여러 개가 함께 보일 때 | 현재 해당하는 화면 없음 |

- 상태 전환 예: 세일판 탭을 누르면 `mbdb_icon_gray500` → `mbdb_icon` 으로 바뀌고 0초부터 재생. 웹은 `is-play` 를 뗐다 다시 붙이면 0%부터 다시 시작합니다.
