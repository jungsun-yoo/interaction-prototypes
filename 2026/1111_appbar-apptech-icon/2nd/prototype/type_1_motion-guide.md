## 이 화면의 핵심 모션 — 이것만 구현

1. **앱테크 로티 재생** — 랜딩 후 이벤트 아이콘 상태별 딜레이(배지 모션 4.5초 · 로티 2.8초 · 정지 이미지 · 없음 0초) 뒤 재생, 291프레임(약 9.7초) 계속 반복 (2)
2. **이벤트 배지 등장** — 랜딩 1초 후 · scale `mds.spring.bouncy` + opacity 0.15s linear (3)
3. **이벤트 배지 사라짐** — 노출 3초 후 · scale `mds.spring.bouncy` + opacity 0.15s linear, 6초 뒤 다시 등장 · 반복 (3)

- 이징 · 스프링은 MDS 모션 토큰 이름입니다. 개발 쪽 같은 이름의 토큰을 쓰면 됩니다 (프로토타입 값은 `src/common/mds-motion.css`).
- 세부 수치(스토어별 로티 · 배지 모양 · 색)는 본문에 있습니다. 위 목록은 범위와 시간 · 이징만 요약합니다.
- 그 외 파일(공통 `common.*`의 폰 프레임 · 상태바 · 페이지 로딩 · 옵션 · 폰 동기화, 헤더 · 빅배너 · 퀵메뉴 · 캠페인 · 광고판 · 바텀네비 등 목업 화면)은 **프로토타입 확인용**입니다. 옮기지 않습니다.
- **실서비스로 바꿀 값**: 이벤트 아이콘(체크인) 상태 — 프로토타입은 옵션 선택, 실서비스는 이벤트 진행 여부와 아이콘 종류(배지 모션 · 로티 · 정지 이미지 · 없음)로 정함.

## 1. 앱테크 아이콘 로티 파일

전문관 스토어별 **아이콘 색상에 맞춘** 로티 파일을 적용합니다. 배경이 투명해서 광고판 진입·이탈 때도 같은 파일을 끊김 없이 그대로 재생합니다.

| 파일 | 아이콘 색 | 적용 화면 |
|---|---|---|
| `ic_appbar_apptech_white.json` | 흰색 | 무신사, 뷰티, 아울렛, 부티크, 킥스 |
| `ic_appbar_apptech_black.json` | 검정 | 스포츠, 유즈드, **마이 페이지** |
| `ic_appbar_apptech_kids.json` | 키즈 주황 `#FF5F00` | 키즈 |

- 위치: `src/lottie/`
- 규격: 84 × 84 (화면 표시 28 × 28), 30fps, 291프레임(약 9.7초), 반복 재생
- 마이 페이지도 앱바 아이콘이 검정이므로 black 버전을 적용합니다. (프로토타입에는 마이 페이지 화면이 없습니다.)

## 2. 앱테크 아이콘 재생 타이밍 (2026-11-26 변경)

랜딩 후 왼쪽 **이벤트 아이콘(체크인)의 상태**에 따라 딜레이를 두고 재생합니다.

| 이벤트 아이콘 상태 | 동전 로티 재생 딜레이 (랜딩 기준) |
|---|---|
| 배지 모션이 있는 경우 | **4.5초** |
| 로티로 재생되는 경우 | **2.8초** |
| 정지 이미지인 경우 | **0초** |
| 없는 경우 | **0초** |

- 랜딩: 화면 진입, 스토어 전환, 홈 재진입.
- 딜레이 동안에는 첫 프레임에 멈춰 두고, 딜레이가 끝나면 0프레임부터 재생합니다.
- 재생을 시작한 뒤에는 **계속 루핑**합니다. 이벤트 배지가 사라지거나 다시 등장해도 로티를 다시 맞추지 않습니다.
- 이전 규칙(배지가 사라지는 순간 재생, 사라질 때마다 0프레임부터 다시)은 없앴습니다.

## 3. 이벤트 아이콘(체크인) 배지 모션

"이벤트" 배지가 체크인 아이콘 오른쪽 위에서 나타났다 사라지기를 반복합니다.

| 항목 | 값 |
|---|---|
| 대상 | 체크인 아이콘의 "이벤트" 배지 |
| 모션 중심점 | 배지 **좌하단** (`transform-origin: 0 100%`) |
| 첫 딜레이 | 랜딩 후 **1초** |
| 등장 | scale `0 → 1` · `mds.spring.bouncy` / opacity `0 → 1` · linear 0.15s |
| 노출 | 등장 모션이 끝난 뒤 **3초** |
| 사라짐 | scale `1 → 0` · `mds.spring.bouncy` / opacity `1 → 0` · linear 0.15s |
| 재등장 | 완전히 사라지고 **6초** 후 다시 등장 |
| 반복 | 등장 → 노출 → 사라짐 → 대기를 계속 반복 |

- "완전히 사라짐"은 opacity가 0이 된 시점(사라짐 시작 후 0.15초)입니다. scale 스프링이 끝나기를 기다리지 않습니다.
- 스토어를 바꾸면 배지 모션은 처음부터(1초 딜레이부터) 다시 시작합니다.

```js
// 웹 (Motion)
const spring = { type: 'spring', stiffness: 322, damping: 26 }; // mds.spring.bouncy
// 등장
Motion.animate(badge, { scale: [0, 1], opacity: [0, 1] }, {
  scale: spring,
  opacity: { duration: 0.15, ease: 'linear' }
});
// 사라짐
Motion.animate(badge, { scale: [1, 0], opacity: [1, 0] }, {
  scale: spring,
  opacity: { duration: 0.15, ease: 'linear' }
});
```

### 배지 모양

| 항목 | 값 |
|---|---|
| 위치 | 체크인 아이콘(28 칸) 기준 x 15, y -2 |
| 크기 | 높이 13, 최소 너비 16, 여백 1.5 / 3, 둥글기 18 |
| 글자 | "이벤트" · Pretendard Medium 8px |

### 배지 색

| 화면 | 바탕 | 글자 |
|---|---|---|
| 무신사 | `#245EFF` | 흰색 |
| 뷰티, 킥스, 부티크, 아울렛 | 흰색 | 스토어 색 |
| 스포츠 | 스토어 색 | 흰색 |
| 키즈 | 스토어 색 | `#3734B8` (키즈 헤더색) |
| 유즈드 | `#000` | 흰색 |
| 광고판 진입 (스포츠·유즈드·키즈 제외) | 흰색 | 광고 색 |

앱테크 아이콘 닷과 알림(종) 아이콘 닷(4px)도 배지 바탕과 같은 색 규칙을 따릅니다.

## 6. 프로토타입 확인용 (실제 앱 UI 아님)

- **스토어 · 이벤트 아이콘 옵션:** 인덱스(`index.html`) 오른쪽 OPTIONS 카드에서 바꿉니다. 프로토타입 안에는 옵션창이 없습니다 (QR로 연 폰은 인덱스에서 고른 값을 따라감).
- **이벤트 아이콘:** 배지 모션 · 로티 · 정지 이미지 · 없음 중에서 고릅니다. 동전 로티는 2장의 딜레이로 재생합니다. '로티'는 체크인 아이콘 로티 파일이 없어 프로토타입에서는 정지 핀으로 보입니다.
- **QR 주소:** 고른 값이 `?opt-store=값&opt-checkin=badge|lottie|static|off`로 붙습니다.
